# Флеш-карточки для английского языка
Телеграм-бот для запоминания английских слова. Бот включает около 100 тысяч флешкарт (https://t.me/proFlashcardsBot).

## Алгоритм интервальных повторений

Система функционирует по принципу постепенного увеличения интервалов между повторениями. Изученные карточки автоматически возвращаются пользователю через заданные промежутки времени: на второй, третий, седьмой, четырнадцатый и девяностый день после первоначального изучения. Данный подход базируется на кривой забывания Эббингауза и позволяет максимально эффективно закреплять материал в долгосрочной памяти.

На каждом этапе повторения система предоставляет возможность отправить карточку на повторное изучение в случае, если материал усвоен недостаточно хорошо.

## ИИ-ассистент для аналитики

Особенностью приложения является интеграция искусственного интеллекта для генерации детализированных отчетов по изучаемым карточкам. ИИ-ассистент анализирует актуальность словарного материала, предоставляя информацию о том, стоит ли изучать конкретное слово или оно считается устаревшим. Система также генерирует практические примеры использования и дополнительную контекстную информацию. Кроме того, ИИ пишет короткие истории в деловом контексте, в которых используются недавно выученные слова.

## Типы упражнений

Приложение включает несколько типов упражнений:
- Ознакомительное (для запоминания)
- Проверка перевода
- Проверка написания слова (с подсказкой)
- Заполнить пробел подходящим словом
- Проверка написания слова (без подсказки)

Каждый тип упражнений может быть индивидуально включен или отключен в зависимости от предпочтений пользователя.

## Дополнительные тренировочные модули

Помимо основных упражнений, приложение предлагает специализированные тренировки:

**Тренировка предлогов** — целенаправленная работа с одной из наиболее сложных грамматических категорий при изучении иностранного языка. Более 300 предложений с пропуском по темам: прилагательные и существительные с предлогами, глаголы, время, место и движение, устойчивые выражения, деловой английский. Тренировка состоит из 10 случайных вопросов; при ошибке бот показывает правильный ответ и правило, а вопрос повторяется через пару вопросов. В конце — результат и список ошибок для повторения. Если в предложении допустимо несколько предлогов, засчитывается любой из них.

**Тренировка фразовых глаголов** — около 85 фразовых глаголов (take off, bring up, get over, put up with и др.) и более 150 их значений. Бот предлагает выбрать значение фразового глагола из четырёх вариантов; у глаголов с несколькими значениями каждый раз спрашивается одно случайное. После ответа бот показывает пример использования и остальные значения глагола.

**Watering Session** — динамичный режим обучения с ограничением по времени, где пользователь должен ответить на вопрос в заданные временные рамки, размер которых можно настраивать.

**Swiper-режим** — инструмент управления карточками, который дает возможность просматривать добавленные в профиль материалы, сбрасывать статистику изучения или повышать приоритет конкретных карточек для их приоритетного появления в упражнениях.

```
Основные функции и команды:
1. Поиск новых карточек:
   - `/f` - покажет популярные карточки.
   - `/f comfy` - найдет карточку для слова comfy.
   - Кнопки в меню карточки:
     - Добавить для изучения - сохранит в профиль.
     - Узнать больше - сформировать отчет через ИИ (рекомендации по изучению).
     - Слушать произношение - пришлет аудио с произношением слова.
     - Знаю - исключит из предложенных.
     - Выйти - завершит режим добавления.

2. Swiper (просмотр карточек):
   - `/s` - откроет Swiper с вашими карточками.
   - `/s ca` - покажет карточки, начинающиеся на ca.
   - `/s ca 100` - покажет карточки ca, выученные на 100%.
   - Кнопки в меню Swiper-а:
     - Учить повторно - сброс статистики.
     - Повысить приоритет - делает карточку приоритетной.
     - Примеры использования - показывает примеры предложений.
     - Произношение - пришлет аудио с произношением слова.
     - Удалить - убирает из профиля.
     - Назад / Вперед - переход между карточками.

3. Упражнения:
   - `/l` - начать упражнения.
   - `/d` - показать активные упражнения и отключить.
   - `/e` - показать отключенные и включить.
   - Изученные в упражнениях карточки попадают в систему интервальных повторений (смотрите раздел 5.Уведомления).

4. Режим Watering session:
   - `/w` - повторение изученных карточек.

5. Уведомления:
   - Интервальные повторения: после упражнений карточка отправляется на повторение через разные интервалы.
     Кнопка Да - показать карточку, Нет - вернуть карточку на повторное изучение.
   - Случайные карточки: добавленные вами для изучения, с коротким текстом от ИИ, где слово используется в контексте.
     Кнопки: Перевод, Примеры, Слушать произношение.

6. Тренировки предлогов и фразовых глаголов:
   - `/pr` - тренировка предлогов из 10 вопросов по всем темам.
   - `/pr verbs` - тренировка предлогов по одной теме; список тем: `/pr topics`
     (adj, nouns, verbs, time, place, phrases, business).
   - `/pv` - тренировка фразовых глаголов: выбрать значение из 4 вариантов (ответ - номер варианта).
   - Выйти - досрочно завершить тренировку и посмотреть результат.

7. Настройки и доп. функции:
   - `/ni 120` - установить периодичность уведомлений для случайных карточек (по умолчанию 60 минут).
   - `/fq 10` - установить количество карточек в упражнениях (по умолчанию 5 карточек).
   - `/wt 3` - установить таймер ответа для режима Watering session (по умолчанию 5 секунд).
   - `/ed picturesque` - отредактировать перевод для карточки picturesque.
   - `/rl 20` - показать последние 20 выученных карточек (в одном сообщении, не более 100);
     кнопка Создать контекст - ИИ напишет короткую историю с этими словами.
   - `/h` - отобразить руководство пользователя
```

## Для разработчиков

Spring Boot 3, Java 17, jOOQ, PostgreSQL, Spring AI (OpenAI-совместимый API). Приложение собирается в WAR и разворачивается в Tomcat.

### Сборка

На этапе `generate-sources` jOOQ генерирует классы по схеме `main` живой базы PostgreSQL, поэтому для сборки нужен доступ к БД:

```bash
export BOT_DB_URL=jdbc:postgresql://host:5432/db BOT_DB_USER=... BOT_DB_PASS=...
mvn clean install                      # сборка и все тесты
mvn test -DexcludedGroups=jooq         # тесты без обращения к БД (DAO-тесты помечены тегом jooq)
```

### Переменные окружения

| Переменная | Назначение |
|---|---|
| `BOT_DB_URL`, `BOT_DB_USER`, `BOT_DB_PASS` | подключение к PostgreSQL |
| `BOT_TOKEN`, `BOT_NAME` | токен и имя Telegram-бота |
| `SERVER_URL` | адрес webhook, который регистрируется в Telegram при старте |
| `WEBHOOK_SECRET` | секрет webhook (1-256 символов `A-Z a-z 0-9 _ -`); Telegram присылает его в заголовке `X-Telegram-Bot-Api-Secret-Token`, запросы без него отклоняются. Если не задан, проверка отключена (в лог пишется предупреждение) |
| `AI_KEY` | ключ API для генерации отчетов и историй |

Не запускайте приложение локально с токеном рабочего бота: при старте webhook перерегистрируется на ваш адрес.

### Контент тренировок

Упражнения хранятся в ресурсах и проверяются при старте приложения и в тестах — ошибка в данных останавливает сборку:

- `src/main/resources/prepositions.yml` — предложения с пропуском: все допустимые ответы и неверные варианты, подобранные вручную (ни один из них не должен подходить к предложению), объяснение правила.
- `src/main/resources/phrasal-verbs.yml` — фразовые глаголы и их значения с примерами. Значениям-синонимам разных глаголов нужно давать общую метку в `senses`, иначе синоним может попасть в неверные варианты.
